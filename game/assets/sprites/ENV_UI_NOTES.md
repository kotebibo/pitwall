# Environment + UI art notes

Generated by `python tools/art/build_all.py` (scripts in `tools/art/`: `pixel.py` helpers, `track.py`, `deco.py`, `ui.py`, `menu_bg.py`, `preview.py`). Edit the scripts, not the PNGs; every random choice is seeded, so a rebuild gives the same pixels. Contact sheet: `preview_env_ui.png` (3x, 3x3 tiling tests, track mock, menu mock).

**World scale:** 1 px = 0.25 m (4 px per metre) for every track texture and decoration. A 128 px texture covers 32 m; a 14 m wide track is 56 px.
**Light:** from the top-left. Baked shadows fall to the bottom-right in one tone: black at 40 % alpha.
**Import:** nearest filter (project default). Tileable textures need `texture_repeat = enabled` on the node that draws them. `vignette.png` looks best with a linear filter.
**Strips:** u runs along the track, v across it, and v = 0 is the track side. For strip textures, set UV.x = metres along the lap * 4 / width_px and UV.y = 0..1 across the strip.
